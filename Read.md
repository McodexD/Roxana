# Roxana Craiu | Professional Portfolio

A cinematic, responsive portfolio website designed for the Swedish job market. This project serves as a digital CV and experience showcase for applications in Office Administration, Customer Success, and English-centric communication roles.

## 🚀 Vision
To rescue the standard "static CV" by creating a high-impact, cinematic experience that highlights professional adaptability across international markets (Romania, UK, and Sweden).

## 🛠️ Built With
* **HTML5/CSS3:** Custom Glassmorphism UI and Parallax effects.
* **JavaScript:** Dynamic interactions and smooth scrolling.
* **AOS (Animate On Scroll):** For premium viewport entry animations.
* **FontAwesome:** For professional iconography.

## 📁 Project Structure
* `index.html`: Core structure utilizing semantic HTML.
* `styles.css`: Advanced CSS featuring backdrop filters and grid layouts.
* `script.js`: Clean JavaScript for animation initialization and UI logic.
* `original-version (Branch)`: Static backup of the legacy design.

## 📈 Optimization for Swedish Employers
* **Clarity:** Focused on direct communication of skills (CRM, Multilingualism, IT Proficiency).
* **Mobile-First:** Fully responsive for recruiters viewing on the go.
* **High Performance:** Optimized assets and minimal library dependencies.
